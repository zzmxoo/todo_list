- 运营者：Tiny·待办事项 开发者

最后更新：2026-11-26

## 一、总述

「Tiny·待办事项」（以下简称"本应用"）是一个 Windows 桌面待办事项小组件。我们的核心设计原则是**数据尽量留在你自己的电脑上**：待办内容、设置项均由本应用直接保存在本机，不经由我们的服务器存储或处理。

本应用**没有**用户账号系统，**没有**任何统计分析、崩溃上报或广告 SDK，也**不会**将你的待办内容上传到任何地方。

## 二、我们在本机存储的信息

以下信息保存在你的电脑上。主数据与 AI 收件箱都在 `%LOCALAPPDATA%\desktoptodo\`；旧版本数据在 `%USERPROFILE%\.desktoptodo\` 或 `%APPDATA%\com.desktoptodo.widget\`，首次启动会自动迁移到新目录。我们无法访问这些数据。

| 数据 | 内容 | 用途 |
| --- | --- | --- |
| 待办事项 | 文字内容、完成状态、截止时间、创建/完成时间 | 实现待办功能 |
| 应用设置 | 窗口位置、透明度、字体、颜色、是否置顶、是否开机自启等 | 记住你的偏好 |
| 背景图片 | 你自行选择图片的副本 | 显示自定义背景 |
| 天气与定位 | 你填写的城市名，或经你授权的经纬度；最近一次天气数据缓存 | 显示天气 |
| AI 收件箱 | 外部 AI 写入、尚未合并的待办 JSON | 跨进程转交待办 |

**关于定位**：点击“定位”后，IP 定位会直接向下列第三方服务发起请求，不会触发系统授权弹窗；只有 GPS 定位才会请求系统授权。坐标仅用于向下述第三方天气服务查询天气，并保存在本机。你可以随时在设置中改填城市名，或清除定位信息。

**删除数据**：本应用不提供云同步，卸载应用后上述数据仍保留在上述目录中。你可以手动删除 `%LOCALAPPDATA%\desktoptodo\` 文件夹以彻底清除；若从旧版本升级，旧目录 `%USERPROFILE%\.desktoptodo\` 与 `%APPDATA%\com.desktoptodo.widget\` 也可一并删除。由于我们不在服务器保存任何用户数据，因此你没有需要向我们申请删除的数据。

## 三、会向第三方发送什么信息

本应用的部分功能需要联网，请求会向下列第三方服务发送必要信息。这些请求**不包含**你的待办内容或身份信息。

| 服务 | 域名 | 发送的信息 | 用途 |
| --- | --- | --- | --- |
| Open-Meteo | `api.open-meteo.com` | 经纬度坐标 | 获取天气预报 |
| Open-Meteo 地理编码 | `geocoding-api.open-meteo.com` | 你输入的城市名 | 把城市名转换为坐标 |
| OpenStreetMap Nominatim | `nominatim.openstreetmap.org` | 经纬度坐标 | 把坐标反查为城市名 |
| BigDataCloud | `api.bigdatacloud.net` | IP 地址（由服务端看到） | IP 定位、逆地理编码 |
| ipwho.is | `ipwho.is` | IP 地址（由服务端看到） | IP 定位备用服务 |
| jsDelivr CDN | `cdn.jsdelivr.net` | 无（仅按年份请求法定节假日数据文件） | 获取节假日数据 |

这些请求会携带常规的网络信息（如 IP 地址、应用标识 User-Agent），这是任何联网请求都无法避免的。各第三方服务对这些信息的处理受其自身隐私政策约束，建议你查阅：

- Open-Meteo：https://open-meteo.com/en/terms
- OpenStreetMap：https://wiki.osmfoundation.org/wiki/Privacy_Policy
- jsDelivr：https://www.jsdelivr.com/privacy-policy

## 四、自定义天气接口

本应用允许你在设置中填写**自定义天气数据接口地址**（如和风天气、彩云天气等）。

如果你使用了该功能，本应用会按你填写的地址发起请求，该地址可能包含你自己的 API Key。**该地址与 Key 仅保存在你本机的设置文件中，我们不会获取、上传或转交他人。**

自定义接口可以填写本机或内网地址（如本地代理 `http://127.0.0.1:8080`）；该例外只对你主动填写的这个地址生效，定位、节假日等其它请求仍禁止访问本机/内网。

由此产生的数据流向由你选择的服务提供商决定，请自行查阅对应服务商的隐私条款。

## 五、我们不收集的信息

- 不收集姓名、邮箱、手机号等身份信息
- 不收集待办内容
- 不收集设备指纹、使用行为、页面停留等统计信息
- 不投放广告，不进行用户画像
- 不向任何第三方出售或共享用户数据

## 六、儿童隐私

本应用不面向 13 岁以下儿童单独收集任何个人信息（实际上不收集任何个人信息）。若你认为我们在不知情的情况下接触了儿童信息，请联系我们。

## 七、你的权利

由于本应用不存储你的数据到我们的服务器，你可以完全自主控制本机数据：

- **查看**：数据以明文 JSON 保存在上述目录，可直接打开查看
- **修改/删除**：删除该目录即可清除全部数据
- **撤回定位授权**：在 Windows「设置 → 隐私和安全性 → 位置」中关闭本应用的位置权限

## 八、政策变更

若本应用新增数据处理行为（例如加入云同步），我们会更新本政策并在应用内或发布页面告知。继续使用即表示接受更新后的政策。
