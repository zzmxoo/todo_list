# 桌面待办小组件

Windows 桌面待办小工具，Tauri 2 + WebView2 实现。深色玻璃拟态界面，无边框、置顶、可拖动。

## 直接运行

```
src-tauri\target\release\desktop-todo.exe
```

首次运行会在 `%APPDATA%\com.desktoptodo.widget\` 下创建 `data.json` 保存待办、设置和天气缓存；
选择的背景图也会复制到该目录，移动原图不影响使用。

## 功能

- **待办列表**：点击空白行或「添加待办」输入内容，回车添加；双击事项文字可修改；悬停显示完成 / 置顶 / 结束时间 / 删除按钮。
- **状态标识**：默认布局在事项左侧显示与内容等高的竖色条，白色常亮、30 分钟内转黄、超时转红、完成后变暗；极简模式下改回原来的圆点 / 方块 / 五角星，配色一致。
- **结束时间**：悬停后点时钟按钮，可选快捷时间（1 小时后、今晚、明天等）或手动选日期时间。
- **天气**：点标题栏的天气胶囊显示/隐藏天气卡片。窗口会自动向左或向右扩展，待办卡片在屏幕上的位置保持不变；时间、日期、城市与天气图标、温度、最高/最低、湿度、风速左右对齐。默认使用 Open-Meteo；也可以在设置中导入自己的天气查询链接，支持和风天气、彩云天气、uapis.cn 的完整请求地址（含 key/token），链接里可用 `{city}`、`{lat}`、`{lon}` 占位符。数据经程序内置的 HTTP 命令请求，不受网页跨域限制。定位后会自动反查并显示城市名。
- **日历**：设置中开启后切换为一整页布局：左侧待办、右侧月历（同一块玻璃面板，中间以细线分隔）。日期格内显示每天的天气图标；带结束时间的事项以彩色横条铺在日期上，从创建时间横跨到结束时间，横条覆盖的日期格数就是事项的持续时长（悬停可查看起止时刻与时长文字），跨周会自动分段，跨月只在当前显示的月份内绘制。同一周内最多同时显示 3 行，多余的可在日期格上滚动鼠标滚轮查看，并在行尾（周日）格用 +n 标出上方 / 下方还各有几条。双击日期格（包括被色条盖住时）会弹出添加待办，回车即添加（默认截止 18:00）。日历区域任意位置都可拖动窗口。
- **导出近期待办**：设置中点「导出」，弹出系统保存对话框选择目录并填写文件名，把最近 30 天已完成的事项导出为 txt；每行格式为「创建时间，完成时间，事项内容」，按完成时间排序。完成时间自本版本起记录，此前的历史完成事项没有该字段，不会出现在导出结果里。
- **日期悬停信息**：在日期格上停留 3 秒，或在日期格上点右键，立即弹出小窗，显示农历、二十四节气（当天是节气时，小窗带节气背景图与节气名）、当天天气，以及一条随机名言。鼠标离开日期格后延迟 1.2 秒消失；期间移到小窗上会保留，离开小窗后同样延迟消失。断网时不弹窗。
- **法定节假日**：内置中国法定节假日安排（每年 1 月 1 日、12 月 20 日自动检查更新），放假日按节日配色铺底并在每天格内标注节日名（元旦 / 春节 / 清明节 / 劳动节 / 端午节 / 中秋节 / 国庆节），悬停小窗里也会显示节日名。查询失败时不显示，不影响其他功能。
- **每日一句**：内置 365 × 4 = 1460 条名言 / 格言 / 励志短句，随机展示且避免连续重复；国内内容不少于 70%，国外名言（含译名）不超过 30%。数据随程序打包，后续无需联网获取。
- **极简模式**：设置中开启后每条待办只占一行，不换行，超出部分用「…」省略；行距更紧凑，「添加待办」紧跟在最后一条事项下面；打开天气卡片时窗口扩展到与天气等高，「添加待办」贴在待办卡片底部。极简模式与日历模式互斥，开启一个会自动关闭另一个。
- **设置**：右上角调节按钮，设置以右侧浮动面板展开（不遮挡左侧待办，可拖动标题栏移动窗口），左侧四个分类图标切换右侧配置页——**界面配置**（透明度、背景色、背景图片、字体、字体颜色）、**系统配置**（极简模式、日历模式、窗口置顶、不在任务栏显示、允许开机启动、导出近期待办）、**天气配置**（城市 / 定位、自定义天气接口）、**关于**（当前显示版本号，后续可扩展检查更新）。字体可选微软雅黑 / 宋体 / 楷体 / 仿宋 / 黑体 / 等线，默认使用当前的微软雅黑栈；字体颜色支持 5 个预设 + 自定义取色，作用于待办、日历等主要文字。背景图片填充在待办 / 天气卡片内部，外层窗口保持透明；支持拉伸 / 平铺 / 填充三种方式，并叠加一层淡色遮罩保证文字可读。透明度 0% 不透明、100% 背景全透，滑杆按线性光 gamma 2.2 换算成 sRGB alpha，让刻度与实际观感一致。开机启动写入当前用户的 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`。
- **窗口**：拖动任意空白处移动，靠近屏幕边缘 20px 内会自动吸附到边缘；位置和尺寸变化后会自动限制在屏幕可用区域内。卡片之间的空隙完全透明，直接显示桌面或下层窗口。开启「不在任务栏显示」后，任务栏按钮隐藏，图标放进系统托盘的隐藏区域；左键托盘图标显示主界面，右键菜单可显示或退出。若主界面正处于边缘收起状态，点击托盘图标会立即弹出，并在 5 秒后（鼠标不在窗口上时）自动缩回边缘。
- **边缘隐藏**：把窗口拖出屏幕超过 1/3 时，主界面先向边缘收缩淡出，再变成一条**两端圆弧**的窄边（上下：半宽、36px 厚；左右：36px 宽、半高）；唤出时窄条淡出、主界面缩放淡入并滑出，整个过程连续。把窗口拖到屏幕上边缘并停留 2 秒会向上收起，保留最后的水平位置。鼠标在窄边上悬停 0.8 秒滑出显示，左键单击 / 双击窄边则立即弹出；移开鼠标后自动收起；显示状态下把窗口拖离边缘即可退出隐藏模式。多显示器下只要窗口仍落在任意屏幕内就不会触发隐藏。

## 开发与构建

需要 Rust（MSVC toolchain）、Visual Studio C++ 生成工具和 WebView2 运行时（Windows 11 自带）。

```powershell
cd src-tauri
cargo build            # 调试版：target\debug\desktop-todo.exe
cargo build --release  # 发布版：target\release\desktop-todo.exe
```

前端在 `ui/` 目录（纯 HTML/CSS/JS，无 Node 构建步骤）；Tauri 配置、Rust 命令在 `src-tauri/`。纯函数集中在 `ui/core.js`；待办、日历、节假日、每日一句的领域规则在 `ui/domain/`（todo / calendar / holiday / quote），只处理普通对象、不碰 DOM；天气解析与各数据源适配集中在 `ui/weather.js`（`WeatherAPI`）。待办写操作统一走 `commitTodos()`，负责保存、重绘与布局。

单元测试在 `tests/` 下，借 WebView2 的 JS 引擎运行：先带调试端口启动程序，再执行测试脚本。

```powershell
$env:WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS='--remote-debugging-port=9222'
src-tauri\target\release\desktop-todo.exe
powershell -ExecutionPolicy Bypass -File tests\run.ps1
```

## 数据与隐私

- 待办和设置只保存在本机 `%APPDATA%\com.desktoptodo.widget\data.json`。
- 天气默认来自 Open-Meteo 免费接口（无需密钥）：按设置中的城市或当前位置查询经纬度后获取实时与 7 日预报。自定义天气链接（含其中的 key / token）只保存在本机 `data.json`，请求由本程序直接发出。
- 法定节假日数据来自 [NateScarlet/holiday-cn](https://github.com/NateScarlet/holiday-cn)（经 jsDelivr CDN 获取），仅保存日期与节日名。
- 名言库随程序内置（`ui/quotes.json`），其中大部分整理自 [lowb](https://www.npmjs.com/package/lowb)（MIT），另含整理的经典名句；运行时不联网获取名言。
- 无遥测、无账号、无云端同步。

## 退出

打开设置，点「退出程序」。
